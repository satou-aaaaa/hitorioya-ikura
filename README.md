# ひとり親・寡婦控除いくら？（hitorioya-ikura）

12月31日の結婚のようす・子・扶養親族・合計所得金額を読んで、ひとり親控除・寡婦控除の額を当てる1日5問の学習ゲーム。正解したら「どの決まり？」（ひとり親・寡婦（離婚）・寡婦（死別・生死不明）・所得が500万円を超える・当たらない）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/hitorioya-ikura/>

- 答えは、国税庁のタックスアンサーの決まりから出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）（ひとり親は35万円：婚姻していない・事実上の夫婦の人がいない・生計を一にする子（総所得金額等62万円以下）がいる・合計所得金額500万円以下。寡婦は27万円：ひとり親に当たらず、夫と離婚して扶養親族がいる、または夫と死別・生死不明。どちらも合計所得金額500万円以下）。
  - No.1171 ひとり親控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1171.htm>
  - No.1170 寡婦控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1170.htm>
- 金額は令和8年分です（ひとり親控除の38万円は令和9年分から）。税額・住民票の続柄の記載・住民税・申告の手続きは出しません。人と金額はつくりものです。
- このゲームはひとり親控除・寡婦控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
